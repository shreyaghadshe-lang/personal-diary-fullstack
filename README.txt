Ledger - Personal Diary
=======================
Plain HTML, CSS and JavaScript. No frameworks, no build step.

Files
-----
index.html  - all screens and page structure
styles.css  - the complete design (light, dark and vintage looks)
app.js      - all the working parts: login, entries, search, filters,
              calendar, moods, streaks, settings, export, storage

How to run
----------
1. Open this folder in VS Code.
2. Double-click index.html, or right-click it and choose
   "Open with Live Server" if you have that extension.
That is all - there is nothing to install.

Notes
-----
- All data is saved in the browser using localStorage, so your diary
  stays on your own computer.
- Create an account on first use, then sign in with the same details.
- Settings has a backup file you can download and restore later.
